# FORM Athletic Club

Responsive gym website with staff profiles, classes, memberships, a program planner, BMI calculator, and merchandise shop.

## Local preview

Use Node.js 22 or newer. Run `node server.mjs` and open http://127.0.0.1:4173. With npm available, `npm start` does the same and `npm run check` validates JavaScript syntax. No dependencies or build step.

## Publish

GitHub Pages publishes from `main` at the repository root. The root `index.html` opens the website in `dist/`; `.nojekyll` preserves the static files. For other hosts, publish `dist/` directly.

## Demo

Payments, accounts, live bookings, and merchandise checkout are not connected. Staff identities, product images, and sample reviews are fictional. Portraits and the FORM emblem were created with the built-in image-generation tool. Local interest and reservation data can be cleared in the membership dialog.
